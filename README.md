# setup-app-practice

## 概要
COACHTECH 教材 Tutorial 9-1「環境構築ハンズオン」で作成した成果物です。<br>
Laravel Sail と Docker を使って、Tutorial 9〜10 のハンズオンで使う開発環境を構築しました。

## 使用技術
- PHP 8.5.12
- Laravel 10.50.3
- Laravel Sail（Docker Compose）
- MySQL, phpMyAdmin

## 学んだこと
- Laravel Sail をでの環境構築
- compose.yaml の記述方法
- sail artisan key:generate による鍵生成の必要性

## 動作確認
本プロジェクトは、Docker環境でLaravel Sailを起動して動作確認できます。<br>
必要な依存パッケージのインストールと環境設定を行い、Laravelの初期画面がブラウザに表示されることを確認してください。<br>
※ 実行環境に応じた設定が必要です。
